## M5 Fanpatch

So uh I actually had this done for a long while but I only now, at 2:38AM on the 10th of May 2026, got bored enough to release it.

This Mod is a sorta Fanpatch for Tuxxego's ModernBox because he can't be assed to fix certain things for whatever reason.

### What this Mod fixes:
1. Old Age Bug:
In newer versions, when loading older save it adds 3000 years to every unit, killing most due to old age.
2. Era "Stuck" in UI
Tux thought it was a good Idea to wrap UI code in Vehicle Code so it updates basically never.
3. MIRV Production Bug
Even if disabled, MIRVs sometimes get produced.
4. Slow Projectiles
Tux coupled them to some dumb scaling meaning they oftentimes just never hit their target. OK Morfos you can stop annoying me about it now.

Plus some more less important ones...

### Configuration Menu:
You can now turn off certain parts of ModernBox, like:
1. Space
2. Eras
3. Kaijus
4. Bombs
5. Biomes

There are also two new menus (Balancing & Extras), just look at the screenshots to figure out what they do.

### How to Install:
1. Ensure you have the latest NML Version installed
2. Download M5 and this Mod from Gamebanana (Unsubscribe from Steam if subscribed!)
3. Move both mods to your Mods folder
4. ENSURE BOTH ARE PROPERLY UNZIPPED
5. M5 is a folder within a folder, move that folder out
6. The Mod should work normally now

### How to Use
1. Open the Vanilla "Others" Tab
2. Click on the Cogwheel button
3. A Menu will open
4. Profit
(Red means something is "On" btw)
